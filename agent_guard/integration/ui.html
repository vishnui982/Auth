Protect an existing tool

Given an initialized V2 gateway and its registered resource verifier, wrap an adapter. The caller identity must come from authenticated transport or trusted setup.

from agent_guard.integration import AgentGuard, EmailAdapter, ResourceVerifier

resource = ResourceVerifier(gateway)
guard = AgentGuard(gateway, "agent1", resource)
email = guard.protect(EmailAdapter())

# Registered local mailbox; destination and body are bound.
result = email.send(to="finance@company.com", body="Summary")
print(result["status"])  # confirmed only with verified mock observation

Separate permission from delivery

Authorized

A signed certificate permits one exact request. It does not establish an effect.

Queued / confirmed

V2 records a durable intent. The integration separately verifies a signed local recipient observation.

Unknown

A lost acknowledgement is uncertain. Reconcile against the recipient record without resending.

What this does—and does not—prove
The theorems cover the Lean semantic model. They do not formally verify all Python, adapters, storage, cryptography, the compiler, or operating system. OPA/Lean agreement is enforced at runtime; universal equivalence of their implementations is not claimed. “Confirmed” refers to the supplied local mock service.

05 / PROJECT OVERVIEW
Every action,
accountable.
An AI agent’s promise is not a permission boundary. ASAP puts that boundary at the tool, where the exact request can be checked before it takes effect.
The problem
Agents can change recipients, leak derived information, reuse old permissions, or delegate beyond their scope.
The mechanism
Canonical requests, stateful policy agreement, signed one-use authorization, and a recipient that verifies the actual request.
The evidence
Signed allow and deny events, replayable history, state commitments, and separate local delivery observations.
The demo narrative
Agent A reads synthetic payroll and writes a summary. Privacy labels follow the derived data. Finance can receive it; the external mailbox cannot. Substitution and replay attacks fail at the recipient. Agent B gains narrowly delegated access, then loses it when the parent is revoked. Finally, a lost acknowledgement is reconciled without duplicating the effect.
Architecture at a glance
LayerResponsibility
Agent / adapterNormalize email, registered REST and MCP tool requests into immutable V2 actions.
Policy / stateTrack labels, grants, revocations, write budgets and resource registrations.
OPA + Lean + PythonAgree on allow/deny and the next active labels. Errors fail closed.
Recipient gateBind actual request, actor, state and nonce to signed authorization.
Audit / deliveryCommit controlled mock effects and observations, verify chains and reconcile uncertainty.
